# Voyah Frida Manager (Русская документация)

Промышленный менеджер автозапуска, мониторинга и перезапуска Frida-скриптов для мультимедийного головного устройства **VOYAH H53 (monza)** на базе Android Automotive 11 (Qualcomm msmnile).

---

## 🌟 Ключевые возможности

* **Каталог Drop-In**: Любой `.js` скрипт, помещённый в `/data/local/voyahmods/hooks.d/` вместе с файлом цели `.target`, автоматически подхватывается и внедряется в процесс.
* **Автозапуск при старте автомобиля**: Интегрируется в каталог загрузочных хуков рут-эксплойта (`/data/local/tmp/boot-hooks.d/60-voyahmods.sh`). Переживает холодную перезагрузку и режим глубокого сна (STR).
* **Самовосстановление при падении приложений**: Если целевой процесс (`com.voyah.car`, `com.voyah.os.carlauncher` и др.) перезапускается, вылетает или смахивается пользователем, супервизор определяет новый PID и повторно инжектит хук в течение 5 секунд.
* **Защита от бутлупа (Automotive-Grade Safety)**:
  * **Boot Gate**: Ожидает завершения старта Android (`sys.boot_completed == 1`) плюс задержку стабилизации 20 секунд.
  * **Circuit Breaker**: Если хук приводит к вылету приложения 3 раза подряд быстрее 15 секунд, супервизор отключает автоинъекцию **только для этого проблемного хука** и ставит флаг `.tripped`.
  * **Безопасность памяти**: Не назначает OOM-иммунитет `-1000` инжекторам, позволяя системе при нехватке памяти мягко остановить скрипт, а не убивать критически важные сервисы автомобиля (камеры кругового обзора, климат, приборку).
  * **Аварийный выключатель**: Создание файла `/data/local/tmp/voyahmods.disable` мгновенно останавливает всю работу менеджера.
* **100% Автономность**: В репозиторий включён скомпилированный бинарник `frida-inject-15` (arm64-v8a) и инструменты первичной настройки root. Любой пользователь может клонировать репозиторий и развернуть систему на автомобиле с нуля.

## ⚡ Быстрый старт

### 0. Первичная настройка (только если на автомобиле ещё нет Root)

Если автомобиль находится в чистом заводском состоянии:

```bash
cd root-prerequisites
./setup_root.sh
cd ..
```

### 1. Установка менеджера

Подключите ноутбук к машине по USB кабелю:

```bash
./install.sh
```

Скрипт `install.sh` автоматически:
1. Проверит наличие root-прав.
2. Загрузит `bin/frida-inject-15` в `/data/local/voyahmods/frida-inject-15`.
3. Установит супервизор и зарегистрирует автозапуск `/data/local/tmp/boot-hooks.d/60-voyahmods.sh`.
4. Запустит фоновый процесс супервизора.
5. Вернёт ADB на USB в безопасный пользовательский режим (`toggle_adb_root.sh off`).

---

### 2. Добавление хука

```bash
./deploy_hook.sh path/to/my_hook.js com.voyah.car
```
Супервизор подхватит его в течение 5 секунд.

### 3. Проверка статуса и логов

```bash
./status.sh
```

Или напрямую через ADB:
```bash
# Главный лог супервизора:
adb shell "cat /data/local/tmp/voyahmods_state/supervisor.log"

# Лог конкретного хука:
adb shell "cat /data/local/tmp/voyahmods_state/<hook_name>.log"
```

### 4. Отключение или удаление хука

* **Временная деактивация**:
  ```bash
  adb shell "touch /data/local/voyahmods/hooks.d/<hook_name>.disabled"
  ```
  Супервизор корректно завершит процесс инжектора за 5 секунд.
* **Полное удаление хука**:
  ```bash
  adb shell "rm -f /data/local/voyahmods/hooks.d/<hook_name>.js /data/local/voyahmods/hooks.d/<hook_name>.target"
  ```

### 5. Полное удаление системы

```bash
./uninstall.sh
```
