# VOYAH H53 — Пакет предварительной настройки Root

В этой папке содержатся автономные инструменты для настройки прав root на Android 11. Они необходимы для того, чтобы утилиты инспекции памяти и внедрения рантайм-хуков (такие как Frida) могли взаимодействовать с процессами и сервисами автомобиля.

---

## Зачем нужен Root?

1. **Релизная сборка Android (`ro.debuggable=0`):** Головное устройство работает на пользовательской (user) прошивке. Стандартные команды `adb root` заблокированы ядром.
2. **SELinux изоляция:** В Android 11 политики безопасности запрещают пользователю `uid=2000(shell)` читать память и выполнять `ptrace` для системных приложений (например, `com.voyah.car`, `com.xiaoma.appstore`).
3. **Аппаратные шины и SOME/IP:** Для отправки сигналов в шину автомобиля требуется вызов нативных сервисов в доверенном системном контексте.

---

## Содержимое каталога

| Файл | Назначение |
|---|---|
| `toggle_adb_root.sh` | Скрипт переключения демона ADB на устройстве между `root` (`uid=0`) и безопасным `shell` (`uid=2000`) |
| `VoyahBootPolicy_ROOT.tar.gz` | Персистентная политика безопасности для демона `xdja_idps`, сохраняемая в раздел `/mnt/vendor/persist` |
| `setup_root.sh` | Автоматический установщик в 1 клик для чистых/заводских автомобилей |

---

## Использование

Если автомобиль находится в чистом заводском состоянии и на нём ещё не настроен root:

```bash
./setup_root.sh
```

Этот скрипт:
1. Загрузит `toggle_adb_root.sh` в `/data/local/voyahmods/toggle_adb_root.sh`.
2. Установит рут-политику в персистентный раздел `/mnt/vendor/persist/`.
3. Перезапустит службу безопасности IDPS.
4. Проверит работу root-доступа через USB ADB.
